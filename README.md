# 📄 license-template

This repository provides a pre-configured, custom license for FriendSMP75 projects. 

## ⚖️ When to Use This License

Use the attached license if your project has the following requirements:
* **The General Public:** Is **NOT** allowed to modify or redistribute the code. They may only download and run it completely unmodified.
* **The Organization (FriendSMP75):** Is granted permission to modify and tune the code exclusively for use on their own personal or public server network. However, they are still **not allowed** to claim ownership or redistribute the code externally without developer permission.

*Note: You are always free to use your own custom license or a standard open-source license (like MIT or Apache 2.0) instead of this one if it better fits your specific project needs.*

---

## 🚀 How to Use This Template

1. Click the green **"Use this template"** button at the top of this repository page to create your new repository.
2. Open your new repository's `LICENSE` (or `LICENSE.md`) file.
3. Replace the placeholder **`[Developer / Copyright Holder Name]`** at the very top with your name, team handle, or GitHub username.
4. Delete the contents of this `README.md` file and replace it with your actual project's documentation!
